# Are there any aspects that make your project unique from similar projects online?

Yes. Pico is not just another voice assistant — it is a complete, customizable, open AI ecosystem built from the ground up. Here's what makes it truly unique:

1. Freedom of AI — Choose Any Provider, Switch Anytime
Most voice assistants lock you into one AI provider. Pico lets you choose from DeepSeek, OpenAI, Anthropic Claude, Google Gemini, Groq, Cohere, Mistral, or even local models via Ollama — and switch with a single click in the web app. No vendor lock-in. No forced upgrades. You own your assistant.

2. Complete Web App Ecosystem — Not Just a Hardware Box
- Most DIY voice assistants are just a microphone and speaker. Pico includes a full production-grade web app with:
- Real-time Dashboard: Device status, usage stats, live activity feed
- Chat History: Full conversation logs with search, filters, and export
- Token Usage Dashboard: Real-time cost tracking with daily/monthly budget limits
- Remote Mode: Use your phone as a microphone and speaker for Pico via WebRTC
- Settings Panel: Change voice, wake word, personality, AI provider, response style
- Multi-User Management: Add and remove family voiceprints with different permissions
- Service Connections: One-click Spotify, YouTube, and Google Calendar integration
- Custom Commands: Create voice macros and routines
- Privacy Controls: Clear chat history, export data, manage voiceprints

3. Smart Interrupt (Barge-In) — Natural Conversation
Most voice assistants make you wait until they finish speaking. Pico supports smart interrupt — you can interrupt it mid-sentence, and it immediately stops, listens, and responds to your new command. This makes conversations feel natural, not robotic.

4. Multi-User Voiceprint Recognition
Pico recognizes who is speaking. Each family member has their own voiceprint, personalized responses, and permissions. Parents can set different access levels for children. This is rare in DIY projects.

5. Three Distinct Interaction Modes
- Pico isn't just a Q&A bot. It has three powerful modes:
- Think: Pure AI creativity — poetry, stories, philosophy, ideas
- Search: Real-time web search with AI summarization
- Think & Search: Research + synthesis — deep, thoughtful analysis

6. Complete Customization — Everything is Changeable
Most assistants let you change your name. Pico lets you change everything:

- Wake word: "Hey Pico," "Computer," "Jarvis" — anything
- Personality: Friendly, formal, witty, creative, wise — or write your own custom prompt
- Voice: Female, male, neutral, any TTS model
- Response style: Concise, detailed, creative
- Commands: Create your own voice macros and routines
- AI provider: Switch anytime

7. Real-Time Streaming to Web App
Pico streams live data to the web app in real-time via WebSockets. You can see the transcription as you speak, watch Pico "think" with a live progress bar, and see the response appear word-by-word — just like ChatGPT.

8. Educational by Design — Built by a 17-Year-Old Creator
Pico is not just a product — it's a learning platform. It teaches hardware assembly, Python programming, AI integration, audio processing, and product design. The complete source code and build guides are available on GitHub. It's a hands-on STEM learning tool for students and creators.

9. Smart Home Ready — Voice-Controlled Home Automation
Pico integrates with MQTT, Matter, and WiZ lights out of the box. You can say "turn on the lights" and Pico controls your home. No extra hubs required. It also supports Samsung TV control and other IoT devices.

10. Affordable — No Subscriptions, Pay Only What You Use
Built on Arduino UNO Q — no expensive hardware. No subscriptions — pay only for the AI tokens you actually use. Knowledge shouldn't be expensive.

11. Open Source — Community-Driven
Pico is fully open source. Anyone can fork it, modify it, and build their own version. This is the opposite of closed commercial assistants.

12. Production-Grade Architecture
Pico uses FastAPI + WebSockets for real-time communication, React + TypeScript for the web app, SQLite for local storage, and Docker for deployment. It's built like a real commercial product, not a hobby project.

13. Privacy by Default
While not the main focus, Pico's architecture naturally protects privacy: wake word detection is local (Porcupine), speaker verification is local (Eagle), and you choose your AI provider. No data collection by default.

14. Voice Activity Detection (VAD) for Seamless Experience
Pico uses Silero VAD to detect when you've finished speaking, so it doesn't cut you off. It also detects when you interrupt it. This makes the interaction feel natural and human.

15. Low Latency — Fast Responses
Pico is optimized for speed: wake word detection under 50ms, STT under 200ms, and end-to-end responses in 2.5-4.5 seconds. It feels responsive and real-time.

## 🚀 Key Features

*   **Universal AI Integration:** Swap backend LLM engines seamlessly. Supports DeepSeek (V4-Flash & V4-Pro), OpenAI, Anthropic, Google Gemini, Groq, or local offline models using Ollama.
*   **True Hands-Free Interaction:** Uses a professional-grade 4-microphone array with XMOS XVF3800 hardware processing for 360° far-field voice tracking (up to 5 meters) and Acoustic Echo Cancellation (AEC).
*   **Smart Interrupt (Barge-In):** Features real-time Voice Activity Detection (VAD) via Silero. Interrupt Pico mid-sentence simply by speaking, without needing physical buttons or wake-word repeating.
*   **Three Interaction Modes:**
    *   `Think Mode`: Pure on-device/LLM generation for reasoning, creative tasks, and coding help.
    *   `Search Mode`: Direct web-search queries with concise summaries.
    *   `Think & Search Mode`: Multi-turn, deep-synthesis queries that research online databases and compile detailed analytical responses.
*   **Sleek Companion Web App:** Control settings, customize responses, view real-time chat logs, monitor token consumption, and manage connected services through a cross-platform dashboard.
*   **Hardware and Smart Home Hub:** Modular connectivity for Spotify streaming, YouTube audio extraction (`yt-dlp`), and direct IoT control (MQTT, Matter, and WiZ smart bulbs).

# Pico OS: Voice AI Core Architecture

A complete end-to-end voice AI pipeline featuring offline STT/TTS, multi-user voiceprint verification, multi-provider LLM routing, smart interruption, and a built-in companion web interface.

---

## Architecture Overview

### 1. Core Voice Pipeline

* **`core/audio_io.py`**: 4-microphone array support with 5-meter far-field pickup, VAD (Voice Activity Detection), RMS dB barge-in detection, and mock input fallback.
* **`core/wake_word.py`**: Picovoice Porcupine wrapper (<50ms target latency) supporting custom keywords (`pico`, `hey pico`, `computer`, `jarvis`).
* **`core/speaker_verification.py`**: Picovoice Eagle integration coupled with `utils/voiceprint_store.py` for multi-user voice enrollment and verification.
* **`core/stt.py`**: Offline Vosk Speech-to-Text engine (200–300ms execution target) with interactive keyboard fallback for testing.
* **`core/tts.py`**: Fast local neural TTS using Piper (includes sine wave generator fallback). Exposes a unified `speak()` function supporting blocking/non-blocking modes and instant barge-in cancellation.
* **`core/interrupter.py`**: Smart Interrupt system—allows users to talk over Pico while it speaks, immediately signaling TTS to halt and re-entering the listening loop.
* **`core/router.py`**: Mode router supporting three operational states:
* **`THINK`**: `"Pico, think..."` — Executes pure local/cloud reasoning.
* **`SEARCH`**: `"Pico, search..."` — Performs live web search and generates a concise summary.
* **`THINK & SEARCH`**: `"Pico, search and think..."` — Performs multi-step deep research and synthesis.


* **`core/memory.py`**: Short-term memory management (20-turn sliding context window per user) plus long-term persistent user preference storage in JSON format.
* **`core/lifecycle.py`**: System orchestration loop managing audio streams, execution state, and precision latency metrics tracking across all stages.

---

### 2. AI Providers & Intelligence Engine

* **Provider Management (`ai/manager.py`)**: Central manager routing prompts dynamically across multiple API and local backends:
* `ai/deepseek.py`
* `ai/openai_provider.py`
* `ai/anthropic.py`
* `ai/gemini.py`
* `ai/groq.py`
* `ai/ollama.py`
* `ai/custom.py`


* **Resource Optimization**: Automated token usage tracking, real-time INR cost estimations, and hot-swapping providers on command (e.g., `"set provider to ollama"`).
* **Personalities (`config/personalities.yaml`)**: Dynamic personality switching including *friendly*, *formal*, *witty*, *creative*, and *wise*, combined with configurable output brevity levels (*concise* / *detailed*).
* **Cost Efficiency**: Supports 100% free local execution via Ollama (₹0/month) or high-efficiency cloud execution via DeepSeek Flash (~₹60–120/month).

---

### 3. Web Search & External Services

* **Search Engine (`services/search_service.py`)**: Primary web search using Tavily API with automatic fallback to DuckDuckGo, formatting scraped web data directly into structured LLM contexts.
* **Media & Playback**:
* `services/spotify.py`: Native playback control via Spotipy.
* `services/youtube.py`: Audio extraction and streaming via `yt-dlp`.


* **Smart Home Integration**:
* `services/smart_home/`: Multi-protocol local automation engine via standard **MQTT**, **Wiz** light discovery, and **Matter** protocol layers.


* **Telephony & RTC**:
* `services/telephony/`: Hardware telephony engine with LTE AT commands (`lte_module.py` / `TinyGSM`), VoIP SIP signaling (`voip.py`), and real-time WebRTC receptionist streams (`agora_receptionist.py`).



---

### 4. Companion Web App (`companion/server.py`)

Built with FastAPI and WebSockets, running locally at `http://localhost:8765` featuring a Stockholm Metro-inspired dot-matrix UI.

* **Live Dashboard**: Real-time status indicators, system logs, active provider views, and latency visualizers.
* **Secure Key Pairing (`pairing.py`)**: Local network Wi-Fi boundary verification generating non-copyable device keys.
* **Remote Mode**: Transforms any browser-capable mobile phone or client into a wireless microphone/speaker client over WebSockets (WebRTC ready).
* **Settings Control**: Live UI adjustment for active wake words, Piper TTS voice models, assistant personalities, and AI providers.
* **Analytics & Limits**: Complete historical chat logs paired with token consumption monitoring and budget safety thresholds (`utils/budget.py`, `utils/token_tracker.py`).
* **Enrollment Suite**: Built-in voiceprint capture UI for adding and managing user profiles.

---

### 5. Onboarding Engine (`onboarding/voice_guided.py`)

An interactive, 11-step voice-guided setup flow that runs upon initial boot up. Generates unique secure device hardware keys and guides the primary owner through their initial voiceprint enrollment.

## Getting Started

### 1. Installation

```bash
cd pico_os

# Install required Python packages
pip install -r requirements.txt

# Configure environment variables (works in mock mode without keys)
cp .env.example .env

```

> **Note:** Open `.env` and add your respective keys if applicable: `DEEPSEEK_API_KEY`, `OPENAI_API_KEY`, `PICOVOICE_ACCESS_KEY`, etc.

---

### 2. Execution Modes

#### Mock Mode (CLI Input / Development)

Run without microphone hardware to simulate interactions via keyboard input:

```bash
python main.py --mock --companion --onboard

```

#### Real Hardware Mode

Run on target hardware (e.g., Arduino UNO Q with array microphone connected):

```bash
python main.py --companion

```

---

### 3. Example Commands (Mock Mode)

Try entering the following prompts directly in mock mode:

```text
hey pico, think what is quantum physics like I'm 10
pico, search latest Arduino UNO Q news
pico, search and think research proposal for voice AI
set personality to witty
set wake word to computer

```

Visit **`http://localhost:8765`** in your web browser to open the companion control dashboard.
